# Track 1 Optimization Plan (Vuoom v2.1.2 -> v2.2.0)

Synthesized from baseline measurements (`PERFORMANCE.md`), dependency/security scans (`pnpm audit`, `cargo-audit`, `cargo-deny`, `cargo-machete`, `cargo tree -d`, `knip`), Phase 2 research (`RESEARCH.md`), and the two full-repo Claude Opus 5.5 read-only audits.

> **Track 1 Scope Constraint**: **Zero visible UI or behavior changes.** All items execute in strict order: **Tier 1** first (one focused commit per verified item/group, measured before/after), then **Tier 2** (targeted refactors with extra care), followed by the Phase 6 optimization loop. **Tier 3** items and **Track 2 UI items** are excluded from Track 1 edits and documented in `MORNING_REPORT.md` / executed in Track 2.

## Tier 3 — Architectural / Breaking Proposals (Do NOT Execute in Track 1 — Document Only)

- **Upgrade `wgpu` 25 -> 29/30 & `glyphon` 0.9 -> 0.12** (breaks `wgpu-hal` & shader/device APIs; fixes `lru`/`memmap2`/`swash`/`windows 0.58` duplicates).
- **Upgrade `solid-js` 1.9 -> 2.0** (breaking reactivity/async model changes).
- **GPU-side BGRA->NV12 compute shader for MP4 export** (~62% less PCIe readback traffic; major shader + Media Foundation / VideoToolbox refactor).
- **Native wgpu surface / compressed preview frames** (replaces raw RGBA loopback WebSocket playback).
- **Streaming audio playback from disk instead of full float32 `AudioBuffer`** (avoids ~230 MB RAM per 10-min 48 kHz stereo track).
- **Tauri IPC binary `Response` API changes for `thumbnails`, `camera_preview_frame` seq#, and `enter_overlay` JPEG/raw bytes**.
- **Dropping GL/Vulkan wgpu backends (`wgpu` `default-features = false`)** (drops fallback on older non-DX12 GPUs; ~2–3 MiB binary savings).
- **Optional Cargo feature gating for `whisper-rs` / captions**.
