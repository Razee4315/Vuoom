# Getting help

- **How do I…?** Start with the [guide](https://razee4315.github.io/Vuoom/guide/), the
  [shortcuts](https://razee4315.github.io/Vuoom/shortcuts/) and the
  [FAQ](https://razee4315.github.io/Vuoom/faq/).
- **Questions and ideas:** [GitHub Discussions](https://github.com/Razee4315/Vuoom/discussions).
- **Something is broken:** [open a bug report](https://github.com/Razee4315/Vuoom/issues/new/choose)
  with your Windows version, the Vuoom version (Settings, About) and steps to reproduce. Logs
  are in `%LOCALAPPDATA%\dev.vuoom.desktop\logs`.
- **Security problems:** please report privately, see [SECURITY.md](./SECURITY.md).

Vuoom is a free project maintained in spare time. Clear reports with steps get fixed fastest.
